# Pershing Square – 13F Portfolio Analysis

## Project Overview

This project presents an Excel-based analysis of Pershing Square's institutional investment holdings, using data from an SEC Form 13F filing.

The spreadsheet organizes the reported portfolio positions and provides an overview of the holdings and their relative weights within the portfolio.

## Data Fields

The Excel workbook includes the following information:

- **Company:** Name of the reported company.
- **Market Value:** Reported market value of each position.
- **Shares:** Number of shares held.
- **Price Per Share:** Price per share.
- **% Weighted Portfolio:** Each position's proportion of the total portfolio market value.

## Excel Features

- Structured data tables.
- SUM formulas for calculating total market value.
- Portfolio weight calculations.
- Financial data organization and presentation.

## Tools Used

- Microsoft Excel
- SEC Form 13F filings

## Objective

The objective of this project is to gain practical experience in financial data analysis and investment portfolio research by working with publicly available institutional holdings data.
